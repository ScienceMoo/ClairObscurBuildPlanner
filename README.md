# Clair Obscur Build Planner

Serverless React app for tracking your current build in _Clair Obscur: Expedition 33_.

## What it does

- 4-column table (one per unlocked character) showing Weapon, Skills, Pictos, and Luminas
- Click "Edit Weapon" / "Edit Skills" / "Edit Pictos" / "Edit Luminas" on any character to pick what you've got equipped, with a searchable list (type to filter, arrow keys + Enter to select)
- Equipping a Pictos also auto-marks the matching Lumina as equipped
- All the pictos, luminas, skills, and weapon data (stats, descriptions) is scraped from the [Clair Obscur Wiki](https://clair-obscur.fandom.com)
